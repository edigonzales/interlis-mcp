# Fachanforderung P05

Für jede Leitung in der Drainageleitung-Sicht muss genau ein Startknoten über Knoten_vonRef verknüpft sein. Keine Verknüpfung entspricht der Anzahl null und verletzt die Regel; genau eine Verknüpfung erfüllt sie. Gezählt werden erreichbare Beziehungsobjekte, unabhängig von ihren Attributwerten. Die vorgelagerte Sichtauswahl bestimmt, welche Leitungen als Drainageleitungen gelten.

Das Eingabemodell erlaubt für diese Rolle höchstens eine Verknüpfung. Mehrere Verknüpfungen sind deshalb bereits strukturell ungültige Daten und kein zulässiger Gegenfall für den Nachweis dieses Constraints. Die fachliche Regel verlangt unverändert genau ein erreichbares Objekt.
