# Fachanforderung P10

Die Sicht v_Bauwerkskomponente darf keine Objekte enthalten. Der Bestand der gesamten Viewpopulation muss exakt null sein. Eine leere Sicht erfüllt die Anforderung; bereits ein einziges berücksichtigtes Objekt verletzt sie, unabhängig von seinen Attributwerten. Die Prüfung zählt alle Objekte der Sicht und verwendet keine zusätzliche fachliche Filterung.
