# Fachanforderung P03

Für jede landwirtschaftliche Nebenausprägung muss die Gewichtung der über Bodeneinheit verknüpften Hauptausprägung strikt grösser sein als die Gewichtung der Nebenausprägung. Gleichheit genügt nicht; eine kleinere Hauptgewichtung ist ebenfalls unzulässig. Die Navigation über Bodeneinheit ist ein einzelner Pflichtbezug.
